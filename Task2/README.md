# Task 2 — Целевой процесс онбординга магазина

## Задача

Спроектировать TO-BE-процесс подключения купленного магазина: с 2 недель до 5 дней,
с минимальным участием человека за счёт автоматического маппинга номенклатуры.

## Артефакты

| Файл | Содержание |
|---|---|
| `onboarding-to-be-v2.drawio.png` | **PNG** — схема процесса для сдачи |
| `onboarding-process.md` | Описание процесса и точки верификации |

## Ключевая идея

Маппинг SKU перестаёт быть ручным конвейером: ИИ сопоставляет номенклатуру с мастер-данными
VitaStore и возвращает уверенность по каждой позиции. Человек проверяет только спорные позиции.
