# Task 3 — Целевая облачная архитектура

## Задача

Убрать локальные серверы, сделать кассу тонким клиентом, абстрагировать разнородное железо
и обеспечить работу магазина при обрыве связи.

## Ключевые решения

- **Cloud POS:** Web POS / PWA на планшете; локальной БД и сервера в магазине нет.
- **HAL (Hardware Abstraction Layer):** единый интерфейс к фискальным регистраторам
  и банковским терминалам (Сбер, Альфа, Ingenico, Verifone) — на Edge через Edge Agent,
  в облаке — через Payment Gateway. Кассовое ПО не зависит от модели оборудования.
- **Офлайн-режим:** локальный журнал операций на планшете, фискализация через локальный
  регистратор, очередь событий и идемпотентная синхронизация при восстановлении связи.
- **Проверка AS-IS:** артефакт 1 содержит связь POS → SAP «Real-time stock & loyalty update
  (REST API)». По артефактам 2–3 real-time нет: обмен идёт ночным FTP (02:00), маппинг — вручную.
  На схеме эта связь показана пунктиром как неподтверждённая; добавлены реальные FTP-потоки.
