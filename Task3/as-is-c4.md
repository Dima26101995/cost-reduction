# AS-IS C4 Container — описание схемы

## 1. Артефакт 1: что было

| Элемент | Тип | Назначение |
|---|---|---|
| Кассир | актор | работает с кассой |
| POS App | контейнер | толстый клиент (Windows, C#), бизнес-логика и драйверы |
| Local DB | контейнер | MS SQL Express, чеки и справочники, сервер в подсобке |
| Фискальный принтер | контейнер | печать чеков (COM) |
| Банковский терминал | контейнер | оплата картой (USB, Ingenico) |
| SAP ERP | система | товары, цены, лояльность |

Связи: Кассир → POS App; POS App → Local DB (JDBC); POS App → Фискальный принтер (USB/COM);
POS App → Банковский терминал (USB); SAP ERP → POS App (REST, real-time).

## 3. Комментарии на схеме

| Комментарий | Где | Что означает |
|---|---|---|
| Real-time stock & loyalty (REST) | SAP ERP → POS App | **не подтверждено**: по артефакту 2 — ночной FTP 02:00, по артефакту 3 — ручной труд |
| Жёсткая привязка к оборудованию | POS App | драйверы встроены; новый банк — новый драйвер (INC-8415: ARCUS-2, 3 недели) |
| 500+ локальных серверов и лицензий | Local DB | 40% ИТ-бюджета на поддержку |
| Отказ диска останавливает магазин | Local DB | INC-8433: диск в подсобке, ETA 4–6 часов |
| Офлайн: лояльность не работает | Local DB | INC-8402: чеки бьются, карты лояльности — тайм-аут |
| Ручной маппинг 80% / 15% ошибок | Товаровед HQ | 500 позиций/час, артефакт 4 |
