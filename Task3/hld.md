# HLD — описание схемы

## 1. На какие вопросы ТЗ отвечает

| Требование ТЗ | Ответ в HLD |
|---|---|
| Избавить магазины от локальных серверов (БД) | Local DB нет: Cloud POS + локальный журнал на планшете |
| Касса — «тонкий» клиент | Web POS / PWA на планшете |
| Разнородное оборудование (Сбер, Альфа, Ingenico, Verifone) | **Edge Agent (HAL)** на месте + **Payment Gateway (HAL)** в облаке |
| Работа при обрыве связи | Локальный журнал, локальный фискальный регистратор, очередь событий |
| Синхронизация при восстановлении связи | Sync Service + идемпотентность (`offline-sync.md`) |
| Компоненты Edge и Cloud | Две зоны: «Магазин (Edge)» и «Облако» |
| Явно выделен HAL/Gateway | Edge Agent и Payment Gateway выделены отдельными контейнерами |

## 2. Состав схемы

### Магазин (Edge)

| Компонент | Технология | Назначение |
|---|---|---|
| Cloud POS | Web POS / PWA на планшете | интерфейс кассира, корзина, чеки |
| Edge Agent (HAL) | локальный сервис | драйверы оборудования, единый интерфейс к железу |
| Локальный журнал | IndexedDB / SQLite | операции офлайн, очередь событий |
| Фискальный регистратор | USB / COM | фискальный чек |
| Банковский терминал | Сбер / Альфа / Ingenico / Verifone | оплата картой |

### Облако (Cloud Backend)

| Компонент | Технология | Назначение |
|---|---|---|
| API Gateway / CDN | HTTPS, TLS | вход, аутентификация, лимиты |
| POS Backend | контейнеры | каталог, цены, промо, корзина, чеки |
| Payment Service | контейнеры | платёжные сценарии, идемпотентность |
| Payment Gateway (HAL) | сервис абстракции | единый интерфейс к терминалам и эквайерам |
| Sync Service | контейнеры | приём офлайн-событий, разрешение конфликтов |
| Event Bus | Kafka | события продаж, платежей, синхронизации |
| Catalog / MDM | сервис мастер-данных | номенклатура, штрихкоды, цены |
| Loyalty Service | сервис | бонусы, профиль клиента |

### Внешние системы

| Система | Назначение |
|---|---|
| SAP ERP | учёт, мастер-данные |
| Банк-эквайер | эквайринг |
| ОФД | фискальные данные |

### Акторы

| Актор | Роль |
|---|---|
| Продавец | работает на кассе |
| Покупатель | оплата, лояльность |

## 3. Связи и протоколы

| Откуда → Куда | Протокол | Что передаётся |
|---|---|---|
| Продавец → Cloud POS | UI | работа на кассе |
| Покупатель → Банковский терминал | — | оплата картой |
| Cloud POS → Edge Agent | HTTP / localhost | локальный API |
| Edge Agent → Фискальный регистратор | USB / COM | печать чека |
| Edge Agent → Банковский терминал | HAL-протокол | оплата |
| Cloud POS → Локальный журнал | IndexedDB / SQLite | запись операций офлайн |
| Cloud POS → API Gateway | HTTPS | запросы каталога и продаж |
| API Gateway → POS Backend | — | маршрутизация |
| API Gateway → Sync Service | HTTPS | синхронизация офлайн-событий |
| POS Backend → Catalog / MDM | — | каталог и цены |
| POS Backend → Loyalty Service | — | бонусы |
| POS Backend → Event Bus | асинхронно | события продаж |
| Payment Service → Payment Gateway (HAL) | — | платёжный сценарий |
| Payment Gateway → Банк-эквайер | HTTPS / SDK | авторизация |
| Edge Agent → Sync Service | HTTPS | догрузка очереди |
| Sync Service → Event Bus | асинхронно | события синхронизации |
| Event Bus → Loyalty Service | асинхронно | начисление бонусов |
| SAP ERP → Catalog / MDM | API / CDC | мастер-данные |
| Фискальный регистратор → ОФД | — | фискальные данные |

## 4. Комментарии на схеме

| Комментарий | Где | Что означает |
|---|---|---|
| HAL на Edge | Edge Agent | единый интерфейс к фискальным регистраторам и терминалам; кассовое ПО не знает модель железа |
| HAL в облаке | Payment Gateway | абстракция эквайеров и протоколов; новый терминал = новый адаптер, без изменения POS |
| Офлайн | Локальный журнал | чек и фискализация — локально; события ждут восстановления связи |

## 5. Границы HLD

HLD описывает кассовую зону. Остальное — в других заданиях:

| Компонент | Где описан |
|---|---|
| AI Matching Service | Task 2 — онбординг магазина |
| Promo Engine | Task 1 — Sourcing Strategy |
| Smart Fulfillment | Task 1 — Sourcing Strategy |
| Analytics / BI | Task 1 — Sourcing Strategy |
| Миграция SAP ERP в облако | Task 1 — Sourcing Strategy (Migrate) |

SAP ERP на HLD показан как внешняя система: для кассы важен интерфейс, а не место размещения.
