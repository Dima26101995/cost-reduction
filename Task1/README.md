## Цветовая кодировка

- 🔴 **Красный** — дорого, дублирование, ручной труд, высокая стоимость поддержки.
- 🟡 **Жёлтый** — работает, но с ограничениями или не даёт конкурентного преимущества.
- 🟢 **Зелёный** — уникальное конкурентное преимущество.
