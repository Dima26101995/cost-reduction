# Task 4 — Расчёт экономической эффективности (TCO)

## Задача

Рассчитать TCO инфраструктуры для 100 магазинов на 3 года, сравнить AS-IS и TO-BE,
определить ROI и срок окупаемости.

## Артефакты

| Файл | Содержание |
|---|---|
| `tco-analysis.md` | Допущения, расчёт по годам, сравнение, ROI, риски |
| `tco.csv` | Таблица для Excel (разделитель `;`) |
